# Bài 4.6 - Quản lý sinh viên bằng C# WinForms
## 1. Giới thiệu
Xây dựng ứng dụng quản lý thông tin sinh viên bằng C# Windows Forms, sử dụng BindingList và BindingSource để liên kết dữ liệu với giao diện.
## 2. Chức năng chính
- Hiển thị danh sách sinh viên trên DataGridView.
- Thêm sinh viên mới.
- Cập nhật thông tin sinh viên.
- Xóa sinh viên.
- Chọn và hiển thị ảnh đại diện.
- Xuất danh sách sinh viên ra file CSV với mã hóa UTF-8.
## 3. Công nghệ sử dụng
- Ngôn ngữ: C#
- Giao diện: Windows Forms
- Liên kết dữ liệu: BindingList và BindingSource
- Xử lý tệp: CSV UTF-8
- Môi trường phát triển: Visual Studio
## 4. Cấu trúc project
- `StudentManager.csproj`: File cấu hình project.
- `Program.cs`: Điểm bắt đầu chương trình.
- `Student.cs`: Lớp lưu thông tin sinh viên.
- `Form1.cs`: Giao diện và xử lý chức năng.
- `README.md`: Tài liệu giới thiệu project.
